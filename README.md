# Dinesh Crystals — Online Crystal Store

Static online store for crystals, geodes & stones, hosted free on GitHub Pages.

**Live:** https://dineshshakya.github.io/crystal-store/

- 36 products (Geodes, On Stand, Hearts, Flats) with names + SKUs from the supplier catalog photos
- Category filters + live search
- Cart (saved in the browser) with free U.S. shipping over $75
- Demo checkout — no real payment is taken yet; orders are confirmed by email

To change a price: edit the `PRODUCTS` list in `index.html` (name, sku, price, img) and push.
Product photos were cropped from supplier-catalog screenshots supplied by the owner — replace with original product photos when available.
